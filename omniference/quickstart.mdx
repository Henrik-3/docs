## Install

Add Omniference to your `Cargo.toml`:

```toml
[dependencies]
omniference = "0.6.0"
```

## Next steps

Create an `OmniferenceEngine`, register a provider (for example Ollama at `http://localhost:11434`) and send requests through it. A full guide is coming; see the [README](https://github.com/Henrik-3/omniference#readme) and the `examples` folder in the repository for now.
